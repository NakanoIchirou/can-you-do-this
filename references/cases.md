# 两个回顾质询案例

这是作者按本 Skill 做的桌面演练，检验分析是否能阻止空泛承诺。没有启动新模型评测、动画生成或真实教材生产，不把演练当成独立行为验证。

## A.《硅晶之梦》：两周额度陷入低质量制作

**输入证据**：两周额度损耗与质量不满来自用户本次陈述，未取得账单验证精确消耗。实际读取已有 silicon-dream-mv Skill 及 lessons.md；记录提到场景关系、重复返工、定格与连续动画混淆，以及转场中间态问题。本轮未播放原片，因此具体画面判断是既有复盘记录，不是本次观影结论。

**建议：放弃继续盲目生成整片的路线；保留项目与已选素材。** 两周投入不是追加投入的理由。既有记录已经指向动作和空间连续性这一关键问题；再补更多画面不会自动解决它。

大概流程：确认连续动画还是已认可的定格形式 → 盘点已选素材 → 选一个难动作和一个转场作样段 → 作者审片 → 才决定是否小批制作 → 剪辑和导出。若形式未知，第一问是“你要角色连续动作，还是接受已有图像的定格/动态短片？目标参考是什么？”

|环节|难点|AI 可负责的部分|必要人工与边界|
|---|---|---|---|
|设定与分镜|“好看”没有统一技术阈值|整理现有设定、提出镜头方案|作者决定风格、表达和可接受形式|
|动作与转场|身份、空间和中间态连续|分析缺陷、形成约束；生成质量待样段验证|作者审美判断；复杂动作可能需要动画师，未询价|
|剪辑和导出|时序、接缝、节奏|有工具后可检验文件及时间轴|完整视听验收不能由抽帧替代|

渠道：FFmpeg 可免费处理现有资产，但需要调试和人工审片；Resolve 免费版可供人工剪辑，学习与操作有成本；Studio 官方 US$295 标价不能证明它能解决本项目动作问题，因此不建议先购买。当前订阅内生成消耗共享额度，不能称“无成本”。外包属于待询价选项，不能保证价格或交期。

下一步只建议 **30–60 分钟现有资产与缺陷盘点、作者约 10–20 分钟选定一个样段目标**；这是未计时的工作预算建议，不是制作交期。新增付费上限建议 ¥0。复杂动作试制单独估算，未选形式前拒绝报整片工期。最多两轮针对性样段修正仍不能保持连续性，就改路线或转人工，不继续批量扩张。

可复制质询：

> 你承诺的是连续角色动画，还是图片运动？请指出最难动作、当前可调用工具及实际成功证据。样段失败两次后，哪条替代路线能保住表达？购买更多额度究竟增加能力，还是只增加重试次数？

**演练结果**：输出了明确建议、首次难点、质量边界、必要人工、免费与付费选择、有限验证；没有把成片可导出当成艺术质量合格。真正样段效果仍未验证。

## B. Re:Learn：个性化教材工具

**输入证据**：既有记忆记录描述“课程笔记/PDF → 可编辑个人教材、补思维断层、跨章组织、例题习题和 PDF”。这是旧构想摘要，可能已变；本轮没有课程原件、学习者测试和完整现行需求。历史上讨论空间不自动授权开发，本轮仅回顾。

**建议：马上推进一节教材的需求澄清与样例验证；整套自动化平台暂时搁置。** 先证明教材真能让用户学懂，再谈产品。把 PDF 换种排版不等于个性化学习。

第一问：“你最想修复哪个具体知识断层？给定一节笔记，是更需要补推导、换解释、补例题，还是重组章节？”先选一种核心收益。

大概流程：选定原始材料及困惑 → 抽取并检查公式/结构 → 对照来源补一处解释 → 加一个例题和可检验的问题 → 用户试学 → 输出可编辑文件；只有有效才做跨章节与自动化。

|环节|首做难点|AI 可负责|用户必须参与|
|---|---|---|---|
|材料与抽取|扫描、公式、缺页；不同课程表述|在可读取条件下整理并标出处|提供有权使用的材料，确认抽取是否失真|
|知识断层修复|流畅解释可能仍错误，且不知道用户卡在哪里|给候选推导/解释并标假设|说清困惑、检查专业内容或请教师复核|
|个性化检验|用户满意不一定代表理解提升|设计与目标对应的小题|真实试学、回答并反馈|
|出版|中文字体、公式、页码、可编辑性|可使用 Quarto 等现成出版链路|最终阅读验收；本轮未渲染验证|

采用现成 Google 来源问答工具可减少资料整理开发，账号与额度仍待查；集成 Quarto 能减少出版代码，但留下抽取和内容验证工作；从零开发上传、知识库、账号和编辑器会先买来维护负担，现阶段收益没有证据。建议先手工串联现成工具与 Markdown。

免费路线：已有文本材料 + Markdown，新增软件现金可为 ¥0，但算入已有订阅消耗和人工。新增付费路线：OCR、模型 API、付费资料工具均需查目标账号报价；目前不建议购买。若原文可复制、只验证一个知识点，建议给首轮 **AI/工具处理与整理 30–90 分钟、人工作业 20–40 分钟** 的预算区间，允许一个返工回合；这是条件化估算，未实测。扫描公式或跨章重写不在此区间内，应另拆工作包。未取得材料前，日历工期不能确定。

验证标准：来源可以逐项追溯；关键公式与原文核对；用户能完成对应的小题并指出解释是否修复断层。任何一项未知，不能宣布完整教材生成能力已验证。两轮解释仍无改善就停止自动扩章，重新定位困惑或转教师辅导。

可复制质询：

> 你替我解决的是排版、检索，还是理解？请用一个具体知识点说明如何验证“我学懂了”。哪些内容来自原文，哪些是你补的？先用现成工具完成一节，自研究竟新增什么不可替代价值？

**演练结果**：将庞大工具构想缩到可讨论的一节，明确先试什么及人工负担；没有承诺学习效果或自动开发平台。
